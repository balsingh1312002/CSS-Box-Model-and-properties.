# CSS Box Model & Position Properties

This project is a simple HTML and CSS practice project created to understand the **CSS Box Model** and different **CSS position properties**.

## 📌 Project Overview

The project contains three boxes inside a container. Each box demonstrates different CSS positioning concepts:

- Normal positioning
- Absolute positioning
- Sticky positioning
- Box sizing
- Margin and padding
- Width and height
- Background colors

## 🛠️ Technologies Used

- HTML5
- CSS3
